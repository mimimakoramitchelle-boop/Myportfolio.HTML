HTML Semantic Elements

What are Semantic Elements?

Semantic HTML uses tags that clearly describe their meaning to both the browser and the developer.

Examplease of semantic elecments

  • header - Represents a container for introductory content or a set of navigational links.
  • nav - Defines a set of navigation links.
  • main - Specifies the main content of a document.
  • section - Represents a standalone section of content.
  • article - Represents an independent piece of content.
  • aside - Defines content aside from the main content.
  • footer - Represents a footer for its nearest sectioning content or root element.
